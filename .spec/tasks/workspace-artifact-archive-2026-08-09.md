# Безопасная уборка артефактов разработки

## Цель

Убрать из корня проекта временные копии, созданные автоматическими VBA-проверками, не удаляя возможности восстановления.

## Границы

- Переносить только корневые папки `_tmp_*`, созданные тестами, и пустую устаревшую `old_form_modules`.
- Использовать существующий архив `Trash`, а не создавать ещё одну папку верхнего уровня.
- Не трогать `CreateOrderBackups`, `CreateOrderReleases`, `CreateOrder.xlsm.modules`, `tools`, `resources`, `tmp`, шаблоны, итоговые приказы и отдельный проект `antigravity_glm_mcp`.
- Зафиксировать назначение папок в `docs/WORKSPACE_LAYOUT.md` и добавить манифест в архив.

## Проверка

1. Все переносимые пути находятся строго внутри корня проекта.
2. В корне не остаётся папок `_tmp_*` и `old_form_modules`.
3. В архиве есть список перенесённых папок и порядок восстановления.
4. `git status` не показывает случайно удалённых отслеживаемых файлов.
