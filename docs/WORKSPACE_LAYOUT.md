# Карта папок проекта

Этот документ отделяет рабочие файлы от резервных копий и одноразовых артефактов.

| Место | Назначение | Правило |
| --- | --- | --- |
| `CreateOrder.xlsm` | Рабочая книга | Изменять только через проверенный установщик при закрытом Excel. |
| `CreateOrder.xlsm.modules/` | Актуальные экспортированные исходники VBA и форм | Главный источник изменений VBA. |
| `tools/` | Установщики и автоматические проверки | Временные копии создаются скриптами сами. |
| `.spec/`, `docs/` | Спецификации, статус и документация | Обновляются вместе с содержательными изменениями. |
| `CreateOrderBackups/` | Резервные копии перед импортом VBA | Не перемещать и не удалять без отдельной политики хранения. |
| `CreateOrderReleases/` | Собранные версии книги | Не является временным мусором. |
| `Trash/` | Безопасный архив устаревших и временных материалов | Можно восстановить файлы вручную; ничего не удаляется автоматически. |
| `Trash/2026-08-09_test-sandboxes/` | Перенесённые папки `_tmp_*` тестов | Нужны только для разбора старых прогонов; новые тесты создадут собственные папки. |
| `tmp/` | Рабочая диагностическая площадка текущих задач | Пока сохранена: содержит снимки форм, PDF и диагностические данные. |
| `workbook-modules/` | Экспорт модулей листов и `ЭтаКнига` для справки | Не импортировать как обычные `.bas`-модули. |
| `graphify-out/` | Карта зависимостей проекта и её исторические снимки | Обновляется командой `graphify update .`. |
| `resources/`, шаблоны `.docx`, итоговые приказы | Рабочие шаблоны и примеры документов | Не переносить автоматически. |
| `antigravity_glm_mcp/` | Отдельный сторонний проект с собственным `.git` и `.venv` | Не относится к CreateOrder; не менять в рамках работ по книге. |

## Как восстановить временную песочницу

Откройте `Trash/2026-08-09_test-sandboxes`, найдите нужную папку и переместите её обратно в корень. В обычной работе это не требуется: скрипт проверки создаёт чистую временную копию сам.
